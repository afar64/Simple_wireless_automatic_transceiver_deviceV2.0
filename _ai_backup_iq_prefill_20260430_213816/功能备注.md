# IQ 调制当前版本功能备注

备份时间：2026-04-30

## 当前功能

- DAC1_OUT1 / PA4 输出 I。
- DAC1_OUT2 / PA5 输出 Q。
- DAC 采样率定义为 2 MHz。
- I/Q 直流偏置固定为 400 mV。
- I/Q 最大峰峰值限制为 300 mV。
- 支持 AM、FM、2ASK、2PSK、2FSK。
- 数字调制当前默认使用规律 0/1 交替码流。
- LFSR 伪随机序列代码保留，后续可通过内部开关恢复使用。

## 当前问题与改进目标

- FM 每点实时计算中包含 64 位乘法和除法，放在 DMA 回调中有超时风险。
- 2FSK 当前从 0 / +20 kHz 方式改进为连续相位的对称频移，例如 -10 kHz / +10 kHz。
- 后续目标是让 FM/2FSK 使用预生成表，DMA 回调中只做表数据搬运或循环切换，降低时域截断和频域底噪风险。

## 协作边界

- 用户已明确说明后续不需要 AI 代编译。
- 本备份用于回滚本次“预生成表优化”前的状态。
